# Rain Walk

A small beginner game project made with Godot.

## Features
- Player movement with "Squash and Stretch" animation
- 2D setup with Y-Sort (Depth perception)
- Advanced TileMap system (Layers for Grass, Trees, and Walls)
- Multi-item Interaction system (Signposts, Statues, Altars)
- Collectible system (5/5 Treasures logic)
- Global Dialogue system with typewriter effect and SFX
- Atmospheric Weather (Rain particles & Dynamic lighting)
- Scene transition system (Portal to Map 2)
- Ambient sound & Sound effects

## Tech
- Godot 4
- GDScript
